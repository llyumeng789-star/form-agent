# form-agent · AI 协作的网申表单自动化框架

> 用 AI 编程智能体（Claude Agent）+ Chrome DevTools Protocol 实现的招聘网申表单自动化。
> 人在回路（human-in-the-loop）设计：AI 写脚本、真机验证，**最终提交永远由人完成**。

## 背景

校招求职需要在十余家不同的招聘系统（北森 Beisen、Moka、51job、企业自建站等）重复填写高度相似的网申表单。这些表单普遍基于 React 私有组件库，程序化填写有大量坑：受控组件、合成事件、虚拟列表、多套面板类名、鼠标点击因页面重排偏移等。

本项目用「AI 智能体自主编写 + 真机回归验证」的方式逐站攻克，并把验证过的交互抽象成可复用的组件库。

## 架构

```
┌─────────────┐   CDP(9222)   ┌──────────────────┐
│ 常驻 Chrome  │◄─────────────►│  Playwright 脚本  │
│ 隔离 profile │               │  (AI 编写/调试)   │
└─────────────┘               └──────────────────┘
        ▲                              │
        │ 手动登录（凭证不出 profile）      │ 复用
        │                              ▼
┌───────┴───────┐              ┌──────────────────┐
│ 个人信息主档    │              │  boekit.mjs       │
│ (gitignore 隔离)│              │  组件交互库        │
└───────────────┘              └──────────────────┘
```

- **`cdp_connect.mjs`** — CDP 连接唯一入口：目标发现、假活自愈（no page target 自动补建）、按 host 复用已打开页面（保持登录态与向导进度）。
- **`boekit.mjs`** — 表单组件交互库，沉淀自十几个站点的真实对抗：
  - `fillText` 受控输入（native setter + input/change 事件）
  - `pick` 下拉面板（兼容 selectList / constant 两套类名，后者需点「确定」落值）
  - `pickCalDate` 日历选择（年面板十年翻页 → 月 → 日，自动兜底年月精度面板）
  - `areaSelect` 级联地区选择（点名称=下钻导航，点图标=选中，逐级推进）
  - `pickRadio` / `upload` / `clickAdd`（动态添加表项）等
  - 慢点击（mousedown → 120-140ms → mouseup）：部分组件快速点击不识别
- **`browser_daemon.sh`** — 隔离 profile 常驻浏览器守护；`--copy/--real` 模式永久禁用（绝不复用用户日常浏览器的登录凭证，避免凭证双活触发风控）。

## 隐私与合规设计

- 个人信息（姓名/证件号/简历等）只存本地 `profile/` 目录且 **gitignore**，与代码物理隔离；
- 浏览器使用独立隔离 profile，目标网站手动登录；
- **AI 不触碰最终提交按钮**：脚本只负责填写与暂存（草稿），提交前由人工全量复核；
- 仓库内不含任何真实个人数据，示例中的信息均为占位符。

## 效果

- 已在 10+ 招聘站点完成网申填写与简历投递（含北森 phoenix、Moka、51job 等框架）；
- 单站表单填写时间从 1–2 小时压缩至约 5 分钟（含 AI 调试迭代）；
- 沉淀 30+ 站点脚本与一套数据驱动的交互库，新站点边际成本大幅下降。

## 快速开始

```bash
# 1. 启动常驻浏览器（隔离 profile）
./browser_daemon.sh        # 用 run_in_background 方式常驻

# 2. 运行示例：在北森表单页自动填写（个人信息来自本地 JSON，不入库）
node examples/beisen_fill_example.mjs
```
